🍳 AIChef

AIChef is a simple React-based recipe generator that helps you turn your available ingredients into delicious recipes using AI. You can enter ingredients, store them in state, view them as a list, and generate AI-powered recipes using Hugging Face API. The generated recipes are displayed beautifully using Markdown rendering.

🚀 Features
🥕 Add ingredients using an input field
📦 Store ingredients in React state
📋 Display ingredients using a dynamic list (ul tag)
🤖 Generate recipes using Hugging Face AI API
🧠 AI-generated responses formatted in Markdown
🎨 Render Markdown into React components using react-markdown
⚡ Simple and responsive UI

🛠️ Tech Stack
React.js (Frontend framework)
JavaScript (ES6+)
Hugging Face Inference API
React Markdown (react-markdown)
CSS (for styling)

📸 How It Works
User enters ingredients into an input field
Ingredients are stored in a state variable
Ingredients are displayed in a list (ul > li)
On button click, ingredients are sent to Hugging Face API
AI returns a recipe in Markdown format
react-markdown converts it into a readable React UI
